Esquema de regiones de cada pagina

index.html
+-------------------------------------------------------------------+
| ENCABEZADO (<header>)                                             |
| ├── Logotipo corporativo (<img>)                                  |
| ├── Título principal ("Rueda libre")                              |
| └── Eslogan / Descripción corta                                   |
+-------------------------------------------------------------------+
| NAVEGACIÓN (<nav> / Enlaces internos y externos)                  |
| ├── Enlace interno a ubicación (#encuentranos)                    |
| └── Enlace externo a tarifas (/paginas/tarifas.html)              |
+-------------------------------------------------------------------+
| CONTENIDO PRINCIPAL (<main>)                                      |
|   ├── SECCIÓN 1: ¿Quiénes somos? (<section>)                      |
|   ├── SECCIÓN 2: ¿Por qué elegirnos? (<section> con lista <ul>)   |
|   ├── SECCIÓN 3: ¿Cómo alquilar? (<section> con lista <ol>)       |
|   └── SECCIÓN 4: Nuestros servicios (<section> con <dl>)          |
+-------------------------------------------------------------------+
| CONTENIDO COMPLEMENTARIO / CONTACTO (<section id="encuentranos">) |
| ├── Título de ubicación                                           |
| ├── Mapa interactivo cliqueable (Imagen con enlace a Google Maps) |
| └── Enlace de correo electrónico (mailto:)                        |
+-------------------------------------------------------------------+
| PIE DE PÁGINA (<footer>)                                          |
| └── Derechos reservados / metadatos de cierre                     |
+-------------------------------------------------------------------+
