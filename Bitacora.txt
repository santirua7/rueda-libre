Selección del control adecuado para cada dato del cliente

1. Nombre completo: Campo de texto de una sola línea (<input type="text">).

2. Correo electrónico: Campo especializado en correo (<input type="email">), que incluye validación automática de formato (arroba y dominio).

3. Celular / Teléfono: Campo de teléfono (<input type="tel">) acompañado de un patrón numérico (pattern) para asegurar la cantidad correcta de dígitos.

4. Fecha de reserva: Selector de fecha de calendario (<input type="date">).

5. Tipo de bicicleta: Lista desplegable (<select>) para ofrecer opciones únicas y ordenadas de selección múltiple cerrada.

6. Mensaje o solicitudes especiales: Área de texto multilínea (<textarea>) para permitir párrafos largos o comentarios detallados.

7. Aceptación de términos y condiciones: Casilla de verificación única o recuadro de marcación (<input type="checkbox">).

Justificación

Elemento / Dato         Control HTML                Justificación Técnica y Semántica
Correo electrónico	    <input type="email">	    Se selecciona este control en lugar 
                                                    de un text genérico porque los 
                                                    navegadores y dispositivos móviles 
                                                    activan automáticamente un teclado 
                                                    adaptado con el símbolo @ y realizan 
                                                    una validación nativa previa al 
                                                    envío, evitando errores de digitación 
                                                    del usuario.

Tipo de bicicleta	    Lista desplegable 
                        (<select> / <option>)	    Es el control ideal cuando el usuario 
                                                    debe elegir una opción única dentro 
                                                    de un conjunto cerrado y predefinido 
                                                    de alternativas (urbana, montaña, 
                                                    eléctrica), optimizando el espacio 
                                                    visual de la interfaz y garantizando 
                                                    que los datos ingresados coincidan 
                                                    exactamente con lo que el sistema 
                                                    espera recibir.

Aceptación de términos	Casilla de verificación 
                        (<input type="checkbox">)	Se elige un checkbox porque representa 
                                                    conceptualmente una acción booleana o 
                                                    de opción única de aceptación explícita 
                                                    ("sí o no"), siendo el estándar legal 
                                                    y de accesibilidad web requerido para 
                                                    consentimientos antes de procesar un 
                                                    formulario.
